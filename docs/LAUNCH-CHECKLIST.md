## 3. Google

- [x] redirect URI للدخول: `https://ai.modaafa.com/api/auth/google/callback`.

- [x] الدومين والصفحة الرئيسية والخصوصية والشروط وحذف البيانات ظاهرة في شاشة الموافقة.
- [ ] مراجعة OAuth مكتملة فعلياً قبل ضبط `GOOGLE_OAUTH_APP_VERIFIED=true`.
- [x] اختبار MCC كبير؛ اكتُشفت الحسابات العميلة وظهرت أسماؤها وإمكانية تبديل الحساب.
- [x] لا تطلب المنصة metrics من MCC نفسه، مع حاجز واختبارات آلية.

## 4. Stripe

- [x] webhook الإنتاج مفعل ويشمل كل الأحداث المطلوبة.
- [ ] تجربة الدفع، التجديد التجريبي، الإلغاء من البوابة، وفشل الدفع تم اختبارها.
- [x] منع تكرار التجربة والفاتورة مطبّق بقيود دائمة واختبارات آلية.

## 6. تجربة العميل

- [x] مستخدم جديد: دخول، بيانات النشاط، ربط Google واختيار الحساب.
- [x] مستخدم عائد يدخل لنفس المساحة ولا يعاد إلى onboarding.
- [x] التبديل بين الحسابات يحفظ الحساب المختار ويحدّث الصفحات المرتبطة به.
- [x] كل نموذج بطيء يعرض حالة انتظار ويمنع النقر المتكرر.
- [x] الجوال وسطح المكتب اجتازا جولة لقطات بلا تجاوز أفقي أو نص متداخل.
- [ ] أول مزامنة وفحص ومحادثة كاملة بحساب يملك اشتراكاً نشطاً.
- [ ] حذف الحساب يلغي الاشتراك ثم يحذف بيانات المنصة ومستخدم الدخول.
