# قائمة الإطلاق الرسمي

## 1. الكود

- [ ] `pnpm check` ناجح على الجهاز وGitHub Actions.
- [ ] لا توجد ثغرات إنتاجية عالية أو حرجة في `pnpm audit --prod`.
- [ ] النشر الإنتاجي مبني من commit معروف ويمكن الرجوع إليه.

## 2. قاعدة البيانات

- [ ] كل ملفات `db/migrations/` مطبقة على Supabase الإنتاج.
- [ ] RLS مفعّل، ولا توجد سياسات تسمح لمستخدم بقراءة بيانات نشاط آخر.
- [ ] الجداول الجديدة موجودة: `oauth_states`, `usage_events`, `job_runs`, `processed_webhook_events`, `billing_trial_grants`, `rate_limit_windows`.
- [ ] وظائف القياس وحدود الطلبات تعمل عبر service role.

## 3. Google

- [ ] redirect URI للدخول: `https://ai.modaafa.com/api/auth/google/callback`.
- [ ] redirect URI لربط الإعلانات: `https://ai.modaafa.com/api/auth/google-ads/callback`.
- [ ] الدومين والصفحة الرئيسية والخصوصية والشروط وحذف البيانات ظاهرة في شاشة الموافقة.
- [ ] مراجعة OAuth مكتملة فعلياً قبل ضبط `GOOGLE_OAUTH_APP_VERIFIED=true`.
- [ ] اختبار حساب مباشر وحساب MCC كبير، مع ظهور الأسماء وإمكانية تبديل الحساب.
- [ ] لا تطلب المنصة metrics من MCC نفسه.

## 4. Stripe

- [ ] الحساب يستقبل المدفوعات وبيانات النشاط مكتملة.
- [ ] أسعار الخطط الستة فعالة، متكررة، بالعملة والفترة الصحيحة وفي live mode.
- [ ] webhook الإنتاج مفعل ويشمل الأحداث الستة المطلوبة.
- [ ] تجربة الدفع، التجديد التجريبي، الإلغاء من البوابة، وفشل الدفع تم اختبارها.
- [ ] لا يحصل المستخدم على تجربة مجانية ثانية بعد الإلغاء أو إعادة التسجيل بنفس الحساب.

## 5. الذكاء والتشغيل

- [ ] فحص Anthropic يجد نموذجاً متاحاً، والمساعد يرجع `ai_backend=model`.
- [ ] يظهر للمستخدم تنبيه واضح إذا استخدم الرد الاحتياطي.
- [ ] مهام `sync-google-ads` و`optimize` نجحت خلال آخر 30 ساعة.
- [ ] Resend domain موثق وتنبيهات الأعطال تصل إلى بريد التشغيل.
- [ ] فحص الصحة المفصل يرجع `launch_ready: true`.

## 6. تجربة العميل

- [ ] مستخدم جديد: دخول، بيانات النشاط، ربط Google، اختيار الحساب، أول مزامنة، أول فحص.
- [ ] مستخدم عائد يدخل لنفس المساحة ولا يعاد إلى onboarding.
- [ ] التبديل بين حسابين يحدث كل الأرقام والجداول بوضوح.
- [ ] كل زر بطيء يعرض حالة انتظار ويمنع النقر المتكرر.
- [ ] الجوال وسطح المكتب بلا تداخل أو نص مقطوع.
- [ ] حذف الحساب يلغي الاشتراك ثم يحذف بيانات المنصة ومستخدم الدخول.

## 7. إطلاق محدود

- [ ] ابدأ بعدد صغير من العملاء لمدة 7 أيام.
- [ ] راقب الأخطاء، زمن الاستجابة، تكاليف Anthropic، معدلات مزامنة Google، وwebhooks Stripe يومياً.
- [ ] لا توسع التسجيل العام قبل إغلاق أي فشل في الربط أو الدفع أو تنفيذ التوصيات.
