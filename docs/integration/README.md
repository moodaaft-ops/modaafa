## الفجوة اللي انسدّت في الدمج
الشات كان يعرض زر "افحص" حتى بعد انتهاء الفحصين المجانيين، فيرجع 402 للعميل. الحين `ChatState.freeAudit` يُقرأ من دفتر الحصة (قراءة فقط، والفشل يعني `unknown` وليس exhausted)، والمخطط يعرض زر الاشتراك عند الاستنفاد، وزر "شيّك على النتيجة" لو فيه فحص شغّال. القراءة والشرح تبقى مجانية.

## الاختبار
قاعدة Postgres معزولة ببيانات اصطناعية (ليست Supabase، والـRPC غير مطبقة على الإنتاج):

    FREE_AUDIT_PG_URL=postgres://.../scratch INTEGRATION_PG_URL=postgres://.../journey npm test

بدون المتغيرين تُتخطى اختبارات قاعدة البيانات (20 اختباراً) وتبقى البقية.
`tests/integration-chat-journey.test.ts` يغطي: فحص أول، إعادة ثانية، استنفاد، عميل مدفوع غير متأثر، عزل A/B، رفض استدعاء حساب غيرك.

## اللقطات
`docs/integration/screenshots/` بثلاثة عروض (320، 390، سطح المكتب): بدون حساب، استنفاد مع اشتراك، بوابة التطبيق للمجاني، معاينة موافقة المشترك.
مصدر الردود: مخرجات `planTurn` الحقيقية على حالات اصطناعية عبر محاكاة `/api/chat/start`. هذا **ليس LLM live**.

## حدود معروفة
