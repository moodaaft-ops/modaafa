- `1c-video-modal.png` يعرض المشغّل بمعرّف فيديو مضبوط في بيئة الفحص فقط. الافتراضي في الإنتاج: لا مشغّل، خطوات مكتوبة، إلى أن يُثبت أن التضمين يعمل.
